About

Personal Clip Uploader is a small command-line tool written and operated by one person (the channel owner). It is not distributed, sold or offered to other users. It uses the YouTube Data API to:

  • upload my own finished videos to my own channel (videos.insert) with title, description, AI-content label and a scheduled publish time;
  • set a thumbnail on my own video (thumbnails.set);
  • create and list my own playlists and add my own videos to them (playlists.list, playlists.insert, playlistItems.insert).

Expected volume: about one upload per day, well inside the default quota.

Privacy Policy

Who uses it: only the owner of the YouTube channel. There are no other users and no accounts on this website.

Data accessed: through Google OAuth 2.0 the tool receives permission to manage the owner's own YouTube account (scope https://www.googleapis.com/auth/youtube). It only sends the owner's own videos, metadata, thumbnails and playlist changes to YouTube. It does not read, collect, analyse or store data about other YouTube users, channels, comments or videos.

Data stored: an OAuth refresh token and the OAuth client credentials are stored in local files on the owner's own computer. Nothing is stored on a server and nothing is shared with, sold to or disclosed to any third party.

Retention and deletion: the stored token can be deleted at any time by deleting the local token file. Access can also be revoked at any time at https://myaccount.google.com/permissions (Google Account → Security → Third-party access). Revoking access also invalidates the token. YouTube API data that the tool handles is only the owner's own data and is not retained beyond the token above.

Cookies / analytics: this web page does not use cookies, trackers or analytics.

Google API Services User Data Policy: the tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes: any change to this policy will be posted on this page.
